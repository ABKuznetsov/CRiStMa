# CrIStMa 0.1.0b1

This is the first public beta of the independent CrIStMa scientific library.
Public APIs may still change before the first stable release.

## Included

- Canonical immutable crystal and molecular structure models.
- Native structural readers for CIF, SHELX RES/INS, VASP, PDB, XYZ and extXYZ.
- Space-group, symmetry-orbit, site-symmetry and Wyckoff calculations backed by
  packaged reference data.
- Composition classification and data-driven inorganic chemistry grammar.
- Periodic neighbours, resolved contacts, coordination shells and coordination
  polyhedra/polygons.
- Structural-unit graphs, exact periodic rank and finite/chain/layer/framework
  blocks.
- Translation-aware locally shortest structural rings, connector atoms and
  crystallographic ring orbits.

## Scientific behaviour

- File-specific representations end at the I/O boundary.
- Calculators are stateless and do not own application workflow or UI state.
- Ring search is performed only inside an existing structural representation
  and parent block.
- Periodic cycles close only when their net lattice translation is zero.
- Search truncation returns an explicit incomplete result and diagnostics.
- No compound names, formulas, site labels or expected ring sizes are encoded
  in the production algorithms.

## Known limits

- The API is beta and may change.
- Organic and metal-organic structural hierarchy is not yet part of this slice.
- Cages, channels, building-unit classification and general topology
  descriptors are future independent analyzers.
- Diffraction and refinement modules are planned but are not claimed by this
  beta.
